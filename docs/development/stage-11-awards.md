# Stage 11 — Awards and Recognition

This slice adds a local dashboard for public professional award pathways.

## Test workflow

1. Start CAPSTONE and open **Awards**.
2. Add an award, its public website and deadline.
3. Link an assessed target. The award card should reuse that target's latest readiness score,
   strengths and gaps.
4. Record nominator and dossier progress, then edit the next action.
5. Archive the pathway and confirm that it disappears without deleting its audit history.

Nominator fields must contain public professional information only. Nomination draft and dossier
document generation remains a later slice; this stage tracks preparation readiness and progress.
