# Stage 10 — Fellowship Dashboard

Stage 10 begins the specialist recognition modules with fellowship pathway tracking. It reuses
the existing target/readiness engine rather than maintaining a second evidence score.

## First slice

- Track standard or custom fellowship programmes, public websites and deadlines.
- Manage workflow status, next action, public professional notes and sponsor/nominator status.
- Link an existing career target and display its latest versioned readiness score, confidence,
  strengths, gaps and recommendations.
- Optionally link an existing opportunity record.
- Highlight deadlines within 30 days and pathways needing sponsor attention.
- Archive completed or abandoned records without deleting history.

Only publicly available professional sponsor details belong in this local MVP.

## Test workflow

1. Create or identify a fellowship target under **Targets & readiness** and assess it.
2. Open **Fellowships** and add the programme.
3. Link the readiness target, set the deadline and record the next action.
4. Confirm the latest readiness version appears automatically.
5. Update sponsor status as the nomination relationship progresses.
